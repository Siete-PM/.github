# SietePM

Somos un estudio de desarrollo web y consultoría de inteligencia artificial con base en Santiago, Chile. Construimos sistemas a medida para organizaciones que necesitan más que una solución genérica: plataformas educativas, sistemas de gestión de contenidos, pipelines de automatización con IA, y arquitecturas que duran.

---

## Qué hacemos

- **Desarrollo web a medida** — Laravel, Livewire, Filament, Nuxt. Arquitectura sólida, código que se puede mantener.
- **Consultoría en IA** — Integración de modelos de lenguaje (Claude API, Ollama) en flujos reales de trabajo.
- **Hosting gestionado** — Infraestructura para clientes que quieren delegar la operación sin perder el control.

Nuestros clientes incluyen universidades, operadores de transporte y empresas de turismo.

---

## Cómo colaborar

Algunos de nuestros proyectos son públicos o tienen componentes abiertos. Si encuentras algo útil:

- **Issues**: reporta bugs o propón mejoras con contexto claro y reproducible.
- **Pull Requests**: bienvenidos si respetan la arquitectura existente. Abre un issue primero si el cambio es significativo.
- **Filosofía**: preferimos código legible sobre código "ingenioso". Si hay que elegir entre elegancia abstracta y claridad operacional, ganamos claridad.

No tenemos un código de conducta largo. La regla es una: tratar a las personas con respeto.
